TS11 — Foundation-model laboratory¶

Goal¶

Complete the twelve-notebook program with real pretrained forecasting checkpoints, keeping future smoothed levels and actual future changes from smoothed inputs as equal research tracks. Compare Chronos-Bolt tiny and mini at 64/256 observations with the filter-aware null and fixed Ridge_10 on six stocks and two monthly climate series. This is a bounded demonstration of one foundation-model family at two sizes, not a survey of all foundation models or a claim that the newest/largest model wins.

Observed results¶

smoothed: Tiny 256 -26.07%, Mini 256 -25.87% MAE skill versus the matched null. returns: Tiny 256 -12.60%, Mini 256 -10.31% MAE skill versus the matched null. Each result averages six stocks, with 40 matched scored origins per stock at h=5. Positive skill is better. Both contexts, both target tracks and both climate datasets are retained in the detailed results. Pretraining overlap is unknown; these historical scores do not establish prospective trading skill.

Setup¶

Default: replay the bundled, digest-checked model inference. All other calculations, Ridge fits, scoring, calibration and charts are recomputed. This runs in the existing TS environment without installing Chronos. To rerun the actual neural inference, install the optional dependencies in requirements-foundation.txt in your chosen Jupyter environment and set RECOMPUTE=True below. Local pinned weights are bundled; neither mode downloads anything. The timing chart always identifies the original fresh-inference run. See FOUNDATION_MODEL_GUIDE.md for exact reproduction steps.

The protocol was frozen before TS11 forecasts/scores. Model inputs are centered, trailing EMA levels, alpha .2; no raw price predictor or full-sample smoother. Both contexts are reported without tuning. Context 256 and horizon 5 are declared primary. Forty calibration origins precede forty evaluation origins, then one latest unscored origin. Stocks use every fifth observed session; climate series every month. Stock horizons are 1–5 sessions; climate horizons are 1–5 months.

Key assumptions¶

Existing histories and adjusted-price vintages were previously examined. Checkpoint training end dates and exact corpus membership are not established for these data. The source vendor's general zero-shot benchmark claims do not establish zero-shot independence here. The two checkpoints were pretrained; no project fine-tuning occurs. This notebook neither changes TS10 trading rules nor issues orders.

Steps¶

1. Start with an identity and a counterexample¶

For EMA $s_t=\alpha x_t+(1-\alpha)s_{t-1}$, a deterministic future EMA path implies $$\widehat{x}_{t+h}={\widehat{s}_{t+h}-(1-\alpha)\widehat{s}_{t+h-1}\over\alpha}, \qquad \widehat{r}_{t,h}=\widehat{x}_{t+h}-{s_t-(1-\alpha)s_{t-1}\over\alpha}.$$ Set $\widehat{s}_t=s_t$. This uses only the smoothed history, including the last two values. EMA is algebraically invertible, so smoothed-only inputs do not imply information reduction. Low lag and denoising do not create return predictability.

The foundation return forecast is the inverse of its marginal median level path, a deterministic point proxy. It is not generally a conditional return mean/median. At alpha .2, the inverse has coefficients 5 and -4 and can amplify forecast noise. Marginal quantiles cannot be differenced into a distribution; the counterexample below has identical endpoint marginal distributions but opposite dependence. We therefore apply the same earlier-error interval calibration to both tracks and all six procedures. No fabricated native return interval is reported.

6. A random-walk control distinguishes catch-up from prediction¶

Generate 128 independent Gaussian random-walk histories after checkpoint retrieval, sigma .01, with no data-dependent model selection. Given each history, future raw increments have conditional mean zero. For any fixed point forecast $m_h$, exact return conditional MSE is $h\sigma^2+m_h^2$. The EMA null is its conditional mean; EMA future variance is $\sigma^2\sum_{j=1}^h(1-.8^j)^2$. The chart averages these analytic conditional risks over generated histories, not noisy realized outcomes. A ratio above one is excess risk versus the known conditional mean. This does not require the foundation forecast to fit zero exactly.

Checks and interpretation¶

Read equal-dataset MAE/MSE skills, asset heterogeneity, paired ranges, interval coverage/width/scores and computational costs together. A larger checkpoint or longer context is not automatically an improvement. EMA inversion can magnify errors in the return track even when smoothed trajectories look convincing. Chronological input integrity cannot establish independence from pretraining.

Program completion¶

TS00–TS11 now cover the original twelve-notebook roadmap. The two foundation checkpoints are real pretrained demonstrations, not randomly initialized stand-ins.
